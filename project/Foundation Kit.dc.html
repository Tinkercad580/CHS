01 · Principles

Nine words, and what each one costs

A principle only means something if it rules a decision out. Each of these carries a rule the rest of the kit obeys.

Simple
One primary action per screen. Everything else is secondary or hidden behind an overflow.
Premium
Generous whitespace, one accent, no gradients or decorative colour. Restraint reads as expensive.
Fast
Nothing animates longer than 320ms. Skeletons appear within 120ms, never a blocking spinner.
Reliable
Money is never shown mid-flight. Amounts carry a state chip: confirmed, provisional or pending.
Intelligent
Every computed number can explain itself. Bill lines show method, rate and the rule they came from.
Professional
Tabular figures for all currency. Indian grouping. Never a rounded rupee where paise matter.
Consistent
The same object looks the same everywhere. A unit chip in the gate app matches the one in billing.
Easy to learn
Every empty state teaches the next action. No screen ends in a dead end.
Pleasant
Motion confirms, it never entertains. Success gets one moment; everything else is quiet.

12 · Motion

Motion

Three durations and two curves. Anything outside this table needs a reason. All of it is disabled under prefers-reduced-motion.

Duration Curve Used for

180ms ease Hover, focus ring, chip and pill state
240ms cubic-bezier(.2,.7,.3,1) Modal, drawer, toast, list reveal, tab switch
loop linear Skeleton shimmer 1.4s, spinner 0.7s only
